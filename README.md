# Experimental 5G Network Performance Analysis in a Semi-Anechoic and Semi-Reverberation Chamber
## About Dataset
This dataset provides a comprehensive view of a private 5G deployment, where detailed metrics are collected in a controlled environment within a semi-anechoic and semi-reverberant chamber. This setting allows for precise evaluation of 5G network performance, including parameters such as latency, bandwidth, and reliability. The data obtained is essential for the development and optimization of advanced communication technologies, providing a solid foundation for research and development in industrial and high-precision environments.

### Configurations:
The variable configurations of 4G/5G are described below:
- **Radio access technologies (Tech):** This parameter distinguishes between LTE and NR technologies.
- **Duplex mode (Duplex):** Communication can occur using Frequency Duplexing Division or Time Duplexing Division.
- **Bandwidth (BW):** Four different bandwidths are tested to assess how network performance scales with higher spectrum allocation (5/10/15/20 MHz).
- **Number of antennas (N_ant):** configurations include "Single Input, Single Output" (SISO) or "Multiple Input, Multiple Output" (MIMO 2x2). 
- **Chamber area (Chamber):** it means the area of the chamber where the transmission takes place, classified into anechoic area (with LoS propagation) and reverberant area (with multipath effect). 
- **Antenna polarization (Polarization):** it is the orientation of the antennas relative to the receiver, classified as vertical (V), horizontal (H), or pointing towards the receiver (P). 

### Key Performance Indicators:
These metrics include:
- Byte transfer [Bytes]
- Troughput [bits/s]
- Retransmitted packets rate
- Internet Control Message Protocol (ICMP) Time [ms]
- Minimum RTT [ms]
- Average RTT [ms]
- Maximum RTT [ms]
- Standard Deviation Round Trip Time [ms].
